Canon Printer Won't Scan: Troubleshooting for Windows and Mac
============================================================

If your Canon printer won't scan, check the connection, selected scanner, and scanning application first. A printer can print normally while its scanning function remains unavailable because printing and scanning use different software components.

You might see a scanner not detected message, a communication error, or a scan that starts but never finishes. Sometimes the document scans successfully, but the saved file is difficult to find.

This guide explains how to troubleshoot a Canon printer not scanning to a computer over USB or WiFi, with practical checks for Windows and Mac.

Why Is My Canon Printer Not Scanning?
-------------------------------------

A scanning problem can involve the printer, computer, connection, or application. Identifying the symptom helps you choose the right steps.

Common causes include:

* The wrong scanner is selected.
* The printer has lost its wireless connection.
* A USB cable is loose or unreliable.
* The scanning application is already in use.
* The scanner driver is missing or incompatible.
* The computer cannot discover the network scanner.
* The destination folder is unavailable.
* The document is positioned incorrectly.
* The automatic document feeder is jammed.
* The printer displays an error that prevents scanning.

Before changing settings, confirm that your printer model includes a scanner. Single-function printers cannot scan documents.

Start with a Simple Scanner Check
---------------------------------

Make sure the printer is switched on and has finished starting. Check its display for errors and close any open covers.

Place one document face down on the scanner glass, aligned with the positioning mark. Close the lid gently.

If your model includes copying, try making a copy from the control panel. A successful copy suggests that the scanning mechanism can capture an image. It does not confirm that the computer connection or scanning software is configured correctly.

Restart the printer and computer, then try scanning one page at a standard resolution.

Canon Printer Prints but Won't Scan
-----------------------------------

When a Canon printer prints but won't scan, the printing connection may be working while the scanner software is missing or incorrectly configured.

Open your scanning application and check the selected device. Choose the scanner associated with your printer model and current connection.

A printer added for basic printing may still need compatible scanning software. Depending on the model and operating system, scanning may use a dedicated driver, a scanning utility, or a built-in application.

Close other scanning applications before trying again. An application that is already using the scanner can prevent another program from accessing it.

Canon Printer Not Scanning to Computer Through USB
--------------------------------------------------

Check the Cable and Port
~~~~~~~~~~~~~~~~~~~~~~~~

Reconnect the USB cable securely at the printer and computer. While testing, connect directly to the computer rather than through a hub or docking station.

Try another USB port. If the scanner disconnects or disappears intermittently, test another compatible cable.

Choose the USB Scanner
~~~~~~~~~~~~~~~~~~~~~~

If your application lists several scanner entries, select the USB-connected device. An old network scanner entry may remain visible even when you have changed to a cable connection.

Wait for the computer to recognize the printer before opening the scanning application again.

Canon Printer Not Scanning Over WiFi
------------------------------------

Confirm the Network Connection
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Check the printer's current wireless network name. Make sure the computer and printer are connected to the same local network.

Guest networks and device isolation settings can prevent communication between devices. Your printer and computer may use different wireless bands if the router allows communication between them.

Reconnect After a Router Change
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

If you changed your router, WiFi name, or password, run the printer's wireless setup again.

Once the printer reconnects, select it again in the scanning application. A saved scanner entry may still refer to the previous network configuration.

Check Wireless Signal
~~~~~~~~~~~~~~~~~~~~~

Move the printer closer to the router if the signal is weak. An unstable connection can interrupt scanning, particularly when transferring large images or multipage documents.

Canon Scanner Not Detected on Windows
-------------------------------------

If your Canon scanner is not detected on Windows, first check whether the computer recognizes the device.

Open the scanning application and review its device list. Select the correct Canon scanner rather than a disconnected or duplicate entry.

If the device does not appear, check the USB or wireless connection before reinstalling software.

For a Canon printer not scanning on Windows 11 or Windows 10, use scanner software intended for the exact model and operating system. A printer driver alone may not provide every scanning feature.

If the scanner appears in one application but not another, focus on the application that cannot find it.

Canon IJ Scan Utility Not Working
---------------------------------

Canon IJ Scan Utility is used with many models, but the appropriate application depends on the printer and operating system.

If IJ Scan Utility is not working, check the product name selected in its settings. Make sure it matches the scanner you want to use.

For a wireless connection, your model's software may include a network scanner selection tool. Confirm the intended device is selected there when applicable.

Close the utility, restart the printer, and reopen the application. Begin with a single-page document scan before changing advanced settings.

If you need to reinstall the utility, choose the version intended for your model. Avoid installing software for a different printer simply because its name is similar.

Canon Printer Won't Scan on Mac
-------------------------------

Check whether the printer appears in your Mac's printer and scanner settings. Select the device and look for a scanning option.

Where compatible, try scanning through Image Capture or the model's scanning application.

If printing works but scanning is unavailable, review whether the device was added with scanning capability and whether the application is compatible with your macOS version.

For network discovery problems, check any relevant local network permission requested by the scanning application. Menu names and available permissions vary by macOS version.

Remove and add the device again only after confirming that its connection works.

Fix a Canon Scanner Communication Error
----------------------------------------

A communication error means the scanning application could not complete its exchange with the scanner. The message alone does not identify the cause.

Check whether another application or computer is using the scanner. Close unused scanning programs and wait for any active task to finish.

For USB scanning, check the cable and direct connection. For wireless scanning, confirm the printer's network status.

A VPN or security application may restrict local device access. Review its local network settings rather than turning off protection broadly.

If an error code appears, record the complete code and the action that triggered it. Different codes may require different troubleshooting.

Scanning from the Printer Panel Does Not Work
---------------------------------------------

Starting a scan from the printer's buttons can require additional computer software and a configured destination.

First, try starting the scan from the computer. If that works, the scanner and connection are functioning, and the remaining issue may involve the printer-panel scan workflow.

Check that the receiving computer is switched on, available on the network, and configured as a destination where required.

The available scan destinations and button functions depend on your model.

Fix Blank, Cropped, or Incomplete Scans
--------------------------------------

Check Document Placement
~~~~~~~~~~~~~~~~~~~~~~~

Place the document against the alignment mark on the scanner glass. Select a scan area or paper size that matches the document.

If using an automatic document feeder, follow its loading diagram. The required page orientation varies between models.

Clean the Scanning Surface
~~~~~~~~~~~~~~~~~~~~~~~~~~

Dust or marks can cause lines and spots. Clean the glass according to the printer's care instructions.

For models with a document feeder, a narrow scanning glass strip may also need cleaning. Do not spray liquid directly into the printer.

Use Simpler Scan Settings
~~~~~~~~~~~~~~~~~~~~~~~~

If scanning stops or takes too long, reduce the resolution and try one page. Higher resolution creates larger files and takes longer to process.

Once a basic scan completes, increase the settings only as needed.

Check Where Scanned Files Are Saved
-----------------------------------

A completed scan may be saved somewhere other than the folder you expected.

Open the scanning application's save settings and check the destination folder, filename, and file type.

Choose a local folder that your account can write to while testing. A disconnected external drive or unavailable network folder can prevent saving.

Frequently Asked Questions
--------------------------

Why is my Canon printer not scanning but printing normally?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Printing and scanning can use different drivers and applications. Check the selected scanner, scanning software, and connection settings.

Why can't my computer find my Canon scanner?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The scanner may be disconnected, selected incorrectly, or unavailable across the network. Confirm the connection before reinstalling software.

Can I scan without using WiFi?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Many multifunction models allow USB scanning. Check your model's connection options and use compatible scanning software.

Why does scanning work from my computer but not from the printer buttons?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Scanning from the printer panel may require a receiving application and a configured computer destination. Check that workflow separately.

Should I reset my printer if it won't scan?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Start with connection, device selection, and application checks. A factory reset is usually unnecessary for initial troubleshooting and may erase saved settings.

Try a Test Scan
---------------

Scan one page, open the saved file, and check that the whole document is visible. Then try your original task.

If your Canon printer won't scan again, note whether the issue involves device detection, image capture, or saving the file. That distinction makes the next troubleshooting step clearer.
